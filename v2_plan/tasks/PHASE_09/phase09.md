# PHASE 09 — DASHBOARD, PERSONAL PREPARATION WORKSPACE, DAILY PRACTICE & LEARNING CONTINUITY

---

# Phase Objective

Build the canonical authenticated preparation workspace for Interview Explainer.

The dashboard must answer five questions immediately:

```text
1. WHAT AM I PREPARING FOR?

2. WHERE DID I STOP?

3. WHAT SHOULD I DO NEXT?

4. WHAT NEEDS REVISION?

5. WHAT SHOULD I PRACTICE TODAY?
```

The dashboard must not become:

* an analytics control panel,
* a collection of decorative cards,
* a gamification screen,
* a duplicate content homepage,
* a wall of percentages,
* a dense productivity application,
* or a second navigation system competing with the public platform.

The intended model is:

```text
PUBLIC DISCOVERY
      ↓
CONTENT LEARNING
      ↓
USER PROGRESS
      ↓
PERSONAL WORKSPACE
      ↓
CONTINUE PREPARATION
      ↓
DAILY PRACTICE
      ↓
REVISION
      ↓
MEASURABLE INTERVIEW READINESS
```

---

# Core Product Principle

```text
THE PUBLIC WEBSITE HELPS USERS
FIND AND LEARN.

THE PERSONAL WORKSPACE HELPS USERS
CONTINUE AND PREPARE.
```

The dashboard should prioritize action over reporting.

Wrong:

```text
WELCOME BACK

12 CARDS
7 CHARTS
4 PROGRESS RINGS
3 STREAK COUNTERS
15 RECOMMENDATIONS
6 PROMOTIONAL BANNERS
```

Correct:

```text
WELCOME BACK

CONTINUE WHERE YOU LEFT OFF
        ↓
TODAY'S PREPARATION
        ↓
AREAS NEEDING ATTENTION
        ↓
YOUR ACTIVE TRACKS
        ↓
SAVED FOR LATER
```

# Canonical Daily Preparation Model

```text
ACTIVE TRACK
      +
CURRENT PROGRESS
      +
IN-PROGRESS CONTENT
      +
DUE REVISION
      +
PRACTICE NEEDS
      ↓
TODAY'S PREPARATION
```

The initial system should be deterministic.

Example:

```text
TODAY

1. CONTINUE LEARNING
   Spring Bean Lifecycle

2. REVIEW
   HashMap Internal Working

3. PRACTICE
   5 Java Concurrency Questions
```

This is substantially more useful than:

```text
YOUR READINESS SCORE: 73%

🔥 12 DAY STREAK

+14% THIS WEEK

TOP 7%

42 HOURS LEARNED
```

unless those metrics later prove genuinely useful.

# Root-Level Product Rule

If the dashboard is too dense:

```text
DO NOT
REDUCE FONT SIZE
```

Fix:

```text
INFORMATION PRIORITY
+
SECTION COUNT
+
CARD COUNT
+
VISUAL HIERARCHY
```

If users do not know what to do next:

```text
DO NOT
ADD MORE RECOMMENDATION CARDS
```

Fix:

```text
ONE CANONICAL
NEXT-ACTION SYSTEM
```

If daily preparation feels random:

```text
DO NOT
ADD AI FIRST
```

Fix:

```text
TRACK SCOPE
+
CURRICULUM ORDER
+
PROGRESS STATE
+
REVISION RULES
+
DETERMINISTIC QUEUE LOGIC
```

If dashboard APIs are slow:

```text
DO NOT
ADD SPINNERS TO EVERY CARD
```

Fix:

```text
AGGREGATION
+
QUERY COUNT
+
INDEXES
+
PAYLOAD SIZE
+
CACHE BOUNDARIES
```
