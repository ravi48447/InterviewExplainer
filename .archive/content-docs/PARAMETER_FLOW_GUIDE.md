## 🔧 How Parameters Connect in Code

### domainAwareGenerator.ts Flow:

```typescript
class DomainAwareGenerator {
  generatePrompt(domainId: string, stackId: string): string {
    // 1. Load Layer 1 (Universal)
    const philosophy = this.loadPhilosophy();
    // → Layer distribution: 15/40/30/15
    // → Quality standards
    // → SEO requirements

    // 2. Load Layer 2 (Domain)
    const domainDef = this.loadDomainDefinition(domainId);
    // → Experience: 1-3 years
    // → Companies: Startups
    // → Daily work: REST APIs, JPA
    // → Difficulty: 20/60/20

    // 3. Load Layer 3 (Stack)
    const domainConfig = this.loadDomainConfig(domainId);
    const stack = this.findStack(domainConfig, stackId);
    // → Exact topics to cover
    // → SEO keywords
    // → Exclusions
    // → Question count: 50

    // 4. Calculate distributions
    const layerCounts = {
      surface: Math.round(50 * 0.15),     // 8 questions (from Layer 1)
      practical: Math.round(50 * 0.40),   // 20 questions (from Layer 1)
      internal: Math.round(50 * 0.30),    // 15 questions (from Layer 1)
      production: Math.round(50 * 0.15)   // 7 questions (from Layer 1)
    };

    const difficultyCounts = {
      easy: Math.round(50 * 0.20),        // 10 questions (from Layer 2)
      medium: Math.round(50 * 0.60),      // 30 questions (from Layer 2)
      hard: Math.round(50 * 0.20)         // 10 questions (from Layer 2)
    };

    // 5. Build comprehensive prompt
    return this.buildPrompt({
      philosophy,          // Layer 1 standards
      domainDef,          // Layer 2 context
      stack,              // Layer 3 specifics
      layerCounts,        // Calculated from Layer 1
      difficultyCounts    // Calculated from Layer 2
    });
  }
}
```

## ✅ Why This Multi-Layer System Works

### Without Layers (Single File):
❌ Repeat same quality standards in every stack config
❌ Repeat experience context in every stack
❌ Hard to maintain consistency
❌ Changes require updating 320 files

### With 3 Layers:
✅ Write quality standards ONCE (Layer 1)
✅ Write experience context ONCE per domain (Layer 2)
✅ Write stack specifics ONCE per stack (Layer 3)
✅ Change Layer 1 → affects ALL stacks automatically
✅ Change Layer 2 → affects all stacks in domain
✅ Change Layer 3 → affects only that stack

## 🎯 Summary: Root to Stack Flow

```
1. MASTER_CONTENT_PHILOSOPHY.md (root)
   → Universal principles for ALL

2. domain-definition.md (domain level)
   → Experience-level context (1-3 years, daily work, companies)

3. domain-config.json (domain level)
   → Contains ALL stacks with exact coverage

4. domainAwareGenerator.ts (script)
   → Reads 1, 2, 3
   → Combines into stack-specific prompt

5. generation-prompt.md (stack level)
   → Auto-generated, combines all layers
   → Super specific for ONE stack

6. questions.json (stack level)
   → Generated by Claude using prompt
   → Or added manually by you
```

**Each layer adds specificity without repeating previous layers!**
