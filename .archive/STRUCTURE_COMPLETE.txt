   npx tsx scripts/domainAwareGenerator.ts generate {domain} {stack}

2. Copy to Claude:
   Open generated prompt file and copy to Claude

3. Save Questions:
   Save JSON response to: domains/{domain}/stacks/{stack}/questions.json

4. Import to Database:
   npx tsx scripts/importToDatabase.ts {domain} {stack} {stack-id}

5. Verify on UI:
   http://localhost:3000/{domain}/{stack}
