# 🎯 Domain: Python Backend Development (1-3 Years Experience)

## 📊 Target Profile

**Role Title**: Mid-Level Python Backend Engineer / Backend Developer
**Experience**: 1-3 years professional experience
**Typical Salary**: $80K-$130K (US), £40K-£70K (UK), ₹12L-₹25L (India)
**Team Structure**: Part of 5-10 person engineering teams
**Reports To**: Senior Engineer or Engineering Manager

---

## 💼 What They Actually Do (Daily Reality)

### Daily Tasks (80% of their time):
1. **Build REST APIs** using Django/FastAPI
   - CRUD endpoints with Django REST Framework
   - FastAPI async endpoints
   - Request validation with Pydantic
   - API authentication

2. **Database Work** with SQLAlchemy/Django ORM
   - Write models and migrations
   - Query optimization
   - Handle relationships
   - Database transactions

3. **Write Tests**
   - Unit tests with pytest
   - Mock dependencies
   - Integration tests
   - API endpoint tests

4. **Async Programming**
   - FastAPI async views
   - Celery background tasks
   - Async database queries
   - WebSocket connections

5. **Debug Issues**
   - API response problems
   - Database query slowness
   - Celery task failures
   - Production bugs

### Weekly Tasks (15% of their time):
- Sprint planning
- Deploy to staging/production
- Code reviews
- Team sync meetings

### Monthly Tasks (5% of their time):
- Performance reviews
- Learning new Python packages
- Documentation updates
